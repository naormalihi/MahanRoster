# האפליקציה (web)

React + TypeScript + MUI בעברית (RTL), Supabase JS.

```bash
cd web
npm install
npm run demo        # נתונים פיקטיביים, בלי שרת: naat / board / new.user, כל סיסמה
cp .env.example .env.local   # להרצה מול Supabase: VITE_SUPABASE_URL ו-VITE_SUPABASE_ANON_KEY
npm run dev
npm test            # בדיקות יחידה (HMAC, קליטת אקסל, תאריכים)
```

## מסכים בגרסה זו

| מסך | מי רואה |
| --- | --- |
| כניסה, אימות דו-שלבי, החלפת סיסמה בכניסה הראשונה | כולם (האימות הדו-שלבי חובה לנע"ת ולממלא המקום) |
| לוח מפורסם: השבוע, שבוע הבא, הסופ"ש הקרוב, 30 יום; סינון לפי גף וסוג; חיפוש שם; הדפסה | כולם |
| טעינת כוח אדם: מפתח יחידה, התאמת עמודות, תצוגה מקדימה של שינויים, טעינה | נע"ת וממלא מקום |

## המספר האישי

המספר האישי לא יוצא מהדפדפן. `src/lib/hmac.ts` הופך כל מספר ל-HMAC-SHA256 עם מפתח היחידה, ורק התוצאה נשלחת לשרת. מפתח היחידה נשמר בזיכרון של הדף בלבד.

בטעינה הראשונה נשמרת בהגדרות "טביעת אצבע" של המפתח. בכל טעינה אחר כך המפתח שהוזן נבדק מולה, כך שמפתח שגוי לא יכול להפוך את כל החיילים ל"חדשים".
