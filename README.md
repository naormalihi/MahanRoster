# מערכת תורנויות

מערכת לשיבוץ תורנויות ביחידה, לפי האפיון ב-Claude Docs. גרסה 1.0 היא כלי עבודה של נע"ת התורנויות, עם לוח מפורסם לצפייה.

## מבנה המאגר

| תיקייה | מה יש בה | מצב |
| --- | --- | --- |
| `solver/` | מנוע השיבוץ (Python + OR-Tools CP-SAT) | אב-טיפוס |
| `db/` | סכמת Supabase, RLS ופונקציות | בהמשך |
| `web/` | ממשק React למסכי הנע"ת וללוח המפורסם | בהמשך |

## מנוע השיבוץ

המנוע מקבל קובץ JSON אחד לכל ריצה (`Problem`) ומחזיר קובץ JSON (`Solution`). אין בו מספרים אישיים ואין מידע רפואי: חיילים מזוהים במזהה אטום בלבד, וכל הנתונים (דרגה מחושבת, אוכלוסיות, ניקוד בסיס, פטורים מאושרים, היעדרויות) מגיעים כבר מחושבים משכבת הנתונים. החוזה המלא מתועד ב-`solver/toranut_solver/models.py`.

```bash
cd solver
pip install -e ".[dev]"

python -m toranut_solver generate --months 1 -o problem.json      # יחידה פיקטיבית
python -m toranut_solver solve problem.json -o solution.json
python -m toranut_solver report problem.json solution.json -o report.md
python -m toranut_solver verify problem.json solution.json          # 1 = הפרת כלל קשיח
pytest
```

### מה המנוע מכסה

- **ניקוד:** יחידות יממה, מכפילי סופ"ש, חג ולילה, ונרמול לפי מקדם ההקלה ביום הביצוע.
- **זכאות (אילוצים קשיחים):** אוכלוסייה, דרגה ומגדר; ממלכ"ת יום רק למשרתי הורה ובעלי פטור מזכה; שח"ר; תוקף מטווח; גיוס, שחרור וחודש חסד; פטורים מלאים וחלקיים; היעדרויות; חסימות תאריך; אילוצים אישיים; משבצות קנס.
- **שיבוץ:** מבצעים ועתודות, מנוחה בין תורנויות (גם לעתודה), עתודת חובה מגף המבצע, שיבוצים קבועים, ותקרה חודשית.
- **הוגנות (אילוצים רכים, בתוך כל אוכלוסייה):** הניקוד הצפוי המקסימלי, הפיזור סביב הממוצע, סופ"שים, עתודות, סופ"שים רצופים, ריכוז בשבוע אחד, ועתודת קבע מגף אחר.
- **מחזור ארוך:** חצי שנה נפתרת חודש אחרי חודש. הניקוד, הסופ"שים והעתודות של כל חודש עוברים לחודש הבא, ותורנויות בסוף חודש נחשבות בבדיקת המנוחה של תחילת החודש הבא.
- **נקודת התחלה:** שיבוץ חמדני כרונולוגי (מי שהניקוד שלו הכי נמוך) נותן ל-CP-SAT פתרון מלא וחוקי מהשנייה הראשונה, והפותר משפר אותו.
- **פלט:** הסבר לכל שיבוץ, משבצות שלא אוישו עם הסיבות, סטטיסטיקת הוגנות, ובודק עצמאי של הכללים הקשיחים.
